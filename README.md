# Pym

A standalone Forge 1.20.1 Pym-particle mod using Pehkui for entity scaling.

## Phase 1
- Pym Particle Generator converts Forge Energy into red or blue Pym particles.
- Red Pym Discs shrink entities.
- Blue Pym Discs grow entities.
- Repeated opposite discs move an entity back toward normal size.
- Structure shrinking is intentionally reserved for a later phase.

## Requirements
- Minecraft 1.20.1
- Forge 47.3.x+
- Pehkui 3.8.2 for Forge 1.20.1
- Java 17

This project is a new implementation inspired by the gameplay concept; it does not bundle LucraftCore or PymTech code/assets.
